# 期权做市研究

本目录归档沪深ETF期权盘口价差、成交流动性与挂单周转可行性的只读研究。
研究数据来自本机MiniQMT `xtdata`，不调用交易接口，不生成券商委托。

## 当前归档

初次全市场扫描日期为 **2026-09-09**，覆盖沪深交易所9个ETF标的下的1,126个期权合约。
本次研究包括：

- 全市场收盘快照、成交额与成交量汇总；
- 重点合约的当日历史Level 1 tick及五档盘口；
- 全天连续竞价时段的时间加权平均盘口价差；
- 相邻快照累计量、成交额和成交笔数差分形成的成交样例；
- 数据核验脚本、统计JSON和SHA256清单。

主要入口：

## 数据语义

- 期权价格单位为元/ETF份，期权数量单位为合约张；本批重点合约每张对应10,000份。
- 历史tick是Level 1快照，包含买卖各五档、累计成交量、累计成交额、累计成交笔数、最新成交价和持仓量。
- 成交增量发生在相邻快照之间。快照时间不是交易所逐笔成交时间，数据不能精确恢复逐笔委托、撤单、真实队列位置或交易所主动买卖方向。
- 盘口价差百分比默认使用有效连续交易时段的时间加权平均，不用单点报价代表全天。
- 期权成交额是权利金成交金额，不是标的ETF名义本金、义务仓保证金或可实现套利收益。
