# 黄金期权历史盈亏逐笔复盘

2026-09-14继续用户“仔细复盘，为何有的交易日赚钱，有的不赚钱，找到原因”的要求。读取09-07至09-10已冻结1184账户，逐笔核对92786个已闭合循环（跨模型重复，不是独立样本），12个结构深入展开。原始1184账本、输入、参数及失败结果都不改。

## 已证实的原因

1. **原始价差不等于成交时仍有相同优势。** 0.2趋势多头09-07挂出最终成交买单时，相对当时中价的折让合计4820元，到成交更新帧只剩730元，等待期间重估−4090元；09-08为2490→430元，变化−2060元。必须区分“看到宽价差”和“在尚有优势时能成交”。聚合L1只支持报价重估的描述，不能把末帧中价当作交易所真实成交瞬间中价。
2. **入场之后持续逆向与恢复的差别。** 相对较好的8跳估值多头＋有限保护＋旧节流，四日入场中价优势均正，但09-07/08持仓中价变化−860/−570元，09-09/10变为+280/+730元。未来60秒中价变动平均−64.14/−16.96/+15/+87元，只是事后诊断，不得作为开仓时可用信号。固定入场IV条件下，同月期货变动解释的持仓贡献约−2511.60/−1624.03/+127.71/+167.37元；剩余部分包括波动率、曲面及盘口重估，不是纯IV套利。时间流逝在此组四日仅约−46.68元，不能当主因。
3. **亏损多数不是已赚却未止盈。** 同一组合63赢共6025.80元、19亏共−5264.60元；亏单仅1笔在已有有效买一快照上出现过扣双费正收益。主版89亏中仅8笔。观察到一帧可执行报价仍不是成交保证；未观察到不等于证明真实市场每一瞬间都没有机会。较好组合亏单持有中位117.5秒、盈利33.5秒，是结果相关，不能反向按实际持仓时长删除亏单。
4. **休市前出口流动性尾部风险。** 09-08 C952增强版11:29:11挂23.60卖出，11:29:12成交，距午休48秒。11:29:40盘口23.34/25.22，11:29:51至56.5附近变21.92/25.50；11:29:56.5按25.50买回净−1903.40元，占当日组合−2021.20元约94%。同月期货959.30→959.23略跌，这不是黄金暴涨把空头打穿，而是卖一扩大后的强制回补成本。这笔成功按有效对手价清仓，不能与旧78个无新报价的清仓失败混为一谈。
5. **不能仅以全天涨跌选日。** 09-08下午期货约跌4.08元/克，但较好组合下午仍+886元，当日亏损集中第二小节。09-07该组合三个小节−1034/−7.2/+72.4，09-08−180.4/−1083.8/+886，09-09为0/+56.6/+446.4，09-10为+6.4/+186.4/+1412.4。规则交易的是特定入场后的短窗口，不能从这4天推出“只做下午”。
