## 完整交易规则

1. 仅买入商品期权权利，不卖空、不加杠杆、不加仓；每合约最多1手，零初始库存。每个模型、合约均有独立固定资金；不足买一手及手续费时等待，不补资、不借用其他账户现金。首轮64合约预算各沿用冻结基线，合计每模型1,698,000元。不同合约不是一个共享资金组合，两个对照模型资金也不共享。
2. 使用交易所合约乘数及最小跳动，内部全部按每手人民币整数分核算。每手单边费用170分，委托请求额外延迟0毫秒。
3. 空仓时：价差大于一跳则买一加一跳、拟卖一减一跳，否则原买卖一。改善后的拟交易毛空间至少覆盖340分加一跳；过去300秒、同一连续时段、有效新鲜行情内，推断主动买和主动卖成交各至少一次，才建立买单。报价无效、相邻行情缺口超过60秒或时段改变清空双侧证据。没有按商品名称或事后盈亏加入白名单。
4. 持仓后：只维护卖单，入场过滤不阻止卖出。入场成交后用新盘口形成卖单，不能认领创建前或同帧已经发生的成交。卖清后才重新判断入场；维持现金和库存跨日连续。
5. 主策略卖价暂不低于买入成本+340分+一跳，向上对齐最小跳动，保护最长300墙钟秒；连续30秒中点低于入场决策中点超过入场价差，或时段改变，提前解除。解除后跟随当前卖一前一跳，允许亏损成交。保护时限不是平仓承诺。对照没有这层保护。
6. 日盘三个时段09:00—10:15、10:30—11:30、13:30—15:00；其外取消纸面委托并保留持仓。没有夜盘输入/决策，不用夜间价格虚构成交。普通日末不强制清仓，这是明确保留的隔夜风险。

## 纸面执行与异常合同

- QMT仅`xtdata`只读行情，每0.5秒轮询一轮64合约，按实际接收顺序处理，不补入晚到历史行情伪造当时交易。每次量增最多使用最新成交价1手证据；方向由前快照买卖一推断，不是交易所逐笔方向。已有最优档的真实排队/冲击仍未校准。
- 每条新委托的生效时刻为当前实际决策时刻。只有后续行情的整个已知成交区间在该时刻之后，才可能撮合；收到价格较早不等于订单在交易所也较早。
- 源行情超过5秒、未来时间超过1秒、日期不同、倒序、无效价格或数量、断线：拒绝相关新决策并留痕；无法确认的区间不分配成交。重复源时间不追加证据、不重复成交；报价变陈旧后仍取消委托。累计量额重置时撤单、清空证据并重新预热。乘数/最小跳动/到期信息在启动、重连时核对，变化则停止。断线及停止时撤掉纸面委托/清空短窗，现金库存不重置。重启先恢复自身账本，再等待新证据；不回放其他模型账户。
- 到期日只允许卖出，禁止新买；超过到期日停止该合约撮合并标记待人工研究结算，不自动行权、不造现金或清零尾仓。当前版本应在到期前由研究人员决定是否结束该账户，后续自动展期另立版本。
- SQLite单实例事务保存输入、源快照、决策状态、委托、取消、成交及日净值。合同与源码哈希在创建时锁定，改变规则不能复用原账户；退出或崩溃后不得重复入账。暂停开仓与恢复开仓通过持久控制状态执行，暂停不取消已有库存的退出资格。
- 估值使用最近有效双侧盘口买一；陈旧估值必须标出时间与陈旧状态，缺失不是零收益。费用、已闭环利润及尾仓贡献完整计入。日报为连续净值差，不是已实现利润或保证可平仓金额。
