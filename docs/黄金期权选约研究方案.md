## 待验证的选约设计

以下是研究设计，不是已实现、已回测或用户确认的永久数字阈值。正式实施改变选约/资金分配后须另立模型身份。

1. 每日从当时实际上市的沪金期权构建池，含认购/认沽及不同到期月和行权价；不按当前存续合约倒推历史池。先记录期限、行权价、标的、合约乘数、最小跳动、数据覆盖和期权方向。
2. 逐时检查拟买卖报价扣费后的人民币空间、近期双向真实成交证据、有效买卖盘口/买二支撑和可用资金；巨大百分比价差但无人交易的报价不是好机会。不因连续相同报价就判定流失效。
3. 在合格者中比较单位资金潜在价差、可观察的成交速度/被动退出条件、标的带来的逆向移动风险。预期成交概率或持仓时长如使用估计，只能用决策之前的数据估计，不能套用该日最终结果。原始价差要减去两侧改善一跳与3.40元双侧费用。沪金单位1000、tick0.02，一手一跳20元；不可与10元附加收益门槛混淆。
4. 引入同月期货方向与期权敏感度时，认购/认沽分别处理。黄金下跌对认购和认沽的影响不同；邻近行权价和月份可作为估值检查，不能将期货绝对变化不经delta/非线性处理直接加在期权价格上。该跨市场参照尚未实现。
5. 初始建议同时观察全池、优先选择少数合约；先测试1个资金名额，再与最多2—3合约对照，数量尚未定案。黄金合约同方向风险高度相关，不能将多行权价当作独立分散。空仓名额按当前信息重新择约，已持仓合约继续原退出逻辑，不为切换标的强行平仓；所有挂买单冻结资金。
6. 评价选择器而不是单合约历史赢家：按时间顺序让模型在当时可见的池里选择，记录入选/拒绝理由、报价、资金和后续全部路径；比较统一交易规则下的固定合约组与动态选约组。保留日度、虚拟成本退出和退出前浮盈亏；需要更完整的期权/标的同步数据及新日期。
