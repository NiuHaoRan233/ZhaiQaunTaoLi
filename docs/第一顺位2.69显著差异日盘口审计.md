# 第一顺位2.69：三个显著差异日的盘口审计

审计日期：2026-09-07。用户要求查看08-13、08-20和08-04，区分已确认交易逻辑的自然代价与模型复刻缺口。本轮仅诊断，未修改任何模型、参数、配置或实时矩阵。唯一主对照为不可变2.63与其直接子版2.69，不使用2.67基线。

## 结论先行

不能把少赚全部解释成“新模型谨慎、老模型扛回来了”。三个日期同时包含：

1. 已有具体证据的复刻/执行缺口：反弹失败后仍被数量门槛挡住退出；卖出后额外等一帧才允许挂未来买单。
2. 逻辑可以成立但未来路径不利：当前有真实高侧需求和承托，先参与占用容量，后来出现更便宜机会。
3. 释放资金后的正常收益：及时退出让下一轮低买高卖成为可能；另有原生客户底仓高卖回补的贡献。
4. 尚需判断的过滤边界：当前空间不足而不接，后来仍可能赚；不能只看事后利润把过滤撤掉。

## 下一步优先级及约束

1. 优先研究恢复后原承托再次失效时的退出连续性。08-13江铜表明5,000张新卖量重置门槛漏掉了有真实破坏的反弹失败，不能让状态恢复成为继续裸持的理由。
2. 分离同帧成交禁令与同帧为未来挂单。08-13三峡385元和08-04三峡98元明确来自后者；仍须保留无真实恢复时不能立即抢回、订单建立帧绝不成交等反例。
3. 保留真实恢复和当前宽空间可以重新参与的方向。08-20有正例，08-04也有机会成本，不能恢复固定旧价/时钟限制来只挑有利结果。
4. 当前窄盘口过滤先继续按真实供需审计，不因事后盈利自动撤销；原生底仓T与普通退出收益分开核算。

本轮不编码新的交易阈值、不注册新模型、不改变2.63/2.69或实时矩阵。报告中的建议未获新实现授权，也不是把每个差额都判为正确/错误。原报告“08-13早退错过反弹”的描述属于汇总级概括，本次盘口证据明确补充此前漏挂出口，不删除原研究记录。
