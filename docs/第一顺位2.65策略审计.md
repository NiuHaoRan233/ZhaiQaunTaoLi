# 第一顺位2.65策略审计

日期：2026-09-05。状态：已实现、已登记的离线候选；未加入前向实时矩阵，未生产晋级。

## 审计结论与范围

用户授权根据口述落地的策略手册检查普通第一顺位，发现有证据的遗漏后自行升级为2.65。本次依据手册、形式化规格、当前2.63父链实现和保存行情，检查参考价、普通承托买入、底仓回补、额外仓退出、孤立盘口保护及退出后再参与的衔接。没有把用户未评论的成交当成认可，也没有把此次检查视为全部历史决策已逐笔得到人工确认。

发现的明确遗漏是：同一普通做T新增仓，通过2.64重做版新增走弱出口退出后不受固定再入封锁，但通过祖先的近保本出口退出后，仍会留下600秒、至少比卖价低0.30元的压价记忆。内部执行通道改变了用户第七十节已经确认的一般原则。同时，重做版文档要求严格后续帧判断，但实际退出当帧仍可能建立下一轮买单。

2.65统一上述行为，保留当前完整入场检查。它没有提高历史累计收益，也没有解决所有再入质量问题。

- 对普通`low_bid_reversion`实际额外仓，近保本与guarded两类风险释放均不写本次固定再入记忆，部分释放同样适用。退出同一市场时间禁止新建额外买单；严格后续帧重新执行父版的参考、承托、走廊、方向、库存和现金判断。

- 配置校验、模型注册、回放入口、看板名称已支持新ID。当前六模型实时配置与历史账户保持原样。

## 证据与排除的误判

08-05江铜11:17:12，普通新增仓以138.001卖出后回到1,000张中性库存。11:17:15买一138.011、卖一138.197，父版只肯挂137.701，恰为旧卖价低0.30元。2.65重新判断后挂138.012，11:17:18才由后续行情成交。聚焦测试另设承托不足的反例，确认解除压价不会直接授权买入。

08-31江铜10:01:28以135.498释放后，2.65于10:02:28买135.322、10:07:34卖135.448，多完成一轮126元毛值的普通做T。父版直到10:23:25才再次买入。

09-02三峡14:13:41，guarded退出成交后当帧盘口买一136.304、卖一136.309；r2当帧建立136.305买单，14:13:44成交。2.65当帧不建新单，14:13:44根据已经变化的买一136.111重新挂136.112，之后随盘口改价，14:14:17以136.152成交。这是“新盘口重新决定”的实际差异，不是新增时间冷却。

最初怀疑guarded卖出会误建通用pending低补身份；运行核验排除了这一点，因为普通第一顺位未开启`enable_downtrend_turn_while_extra_inventory`。据此没有改动共用pending记账。孤立低卖反向一致性、嵌套承托、客户底仓与额外仓分离等已有机制也没有因本次检查而重写；仍须随新案例继续审计其覆盖范围。
