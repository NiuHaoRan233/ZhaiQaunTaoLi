# 第一顺位2.67报价精度审计

2026-09-05，用户恢复额度后授权继续优化普通第一顺位。2.66 r3及更早模型保留不可变，本轮不改变实时矩阵。

## 事前发现

先对2.66 r3的63个受阻盘口检查退出后新成交证据。只有08-14江铜6帧呈现退出后买量占优，且仅约1,000张买量；当时卖一仍下移约0.30元。这个反例不足以支持仅按退出后买量解除风险，不新增类似此前被否决的1,000张解锁门槛。

随后发现确定的数值问题：原生第一顺位报价先用二进制浮点加减一厘，再用Decimal向下取整。原本位于合法价位的结果，可能表示为138.09799999999998，随后变成138.097，而数学上的一厘报价应为138.098。买价也会因行情浮点表示成为136.61599999999999，原本应改善为136.616却回到136.615。

保持父版行为不变的24日双债探针共记录4,166次这种取整事件，包含3,683次卖侧与483次买侧计算。它们是计算帧次，不等于独立委托或成交笔数。08-04三峡09:37:27卖一138.099，原生卖单计算138.09799999999998并截到138.097；09:59:36买一136.61499999999998，改善后截到136.615。该缺口直接违反“数学上改善一厘”的报价意图，不依赖事后盈亏判断。

## 运行前登记的修正

新ID为maker_priority_v2_67_candidate，直接父ID为不可变maker_priority_v2_66_candidate_r3。唯一profile变化为normalize_native_priority_price_grid=True。只在原生第一顺位被动买卖报价的最终向下取整时，若计算结果距离最近合法价位不超过十亿分之一档，先消除浮点格点噪声；真实的非格点价格仍按向下取整处理。不开启旧模型、queue、Windfall和共享账户的新精度行为，不重写全局价格规则，也不改变交易证据阈值。

这会改变订单价格和可能的成交、库存路径，所以使用独立模型身份。它不保证收益增加；较高卖价或真正改善一厘的买价也可能改变成交机会，需要完整回放。精度修正不自动修改已有窄盘口执行规则、其他主动价格或经济边界。

## 尚未解决的主问题

2.65至2.66实验的难点仍是：风险释放可以更符合“坏了就走”，但再次挂回的盘口需要区分持续下压与重新形成的做T机会。旧卖压一刀切会错删合法首次入场；只根据退出后少量买量解锁又会忽略仍在下移的卖档。本次没有找到足以编码的统一新规则，保留这些反例，不把精度修复带来的小幅改善包装成判断能力突破。
