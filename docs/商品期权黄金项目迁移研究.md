# 商品期权借鉴mAu项目的日内研究

## 来源与边界

2026-09-13用户提供自己的[mAu项目](https://github.com/NiuHaoRan233/mAu-TD-Market-Making/tree/290867798c02b33f5b284f83a8d81e528cf42878)，用于寻找商品期权优化思路。读取固定提交`290867798c02b33f5b284f83a8d81e528cf42878`的策略文档与源码，未执行其交易程序。

关键源码：`研究mau三小时增收_v4.py:99`的Reference用期货现价加EWMA基差估计mAu参照价，至少60秒、3次观察后可用；`研究mau迁移Au单手方法_v5.py:76`先检查价差、孤立买一、期货短时逆向变化与扣费后参照价优势，再选合格侧；同文件113行的持仓出口被动跟随对手方向盘口，没有成本底价。`研究mau一手保证金额度_v7.py:54`对长仓采用快慢参照价较低者，一手保证金只容许一个开仓意图或持仓。

区别不能抹去：黄金项目允许先空后多，期权本研究仅买入后卖出；黄金的0.50元/克阈值和比例费用不能套用于不同期权乘数；黄金历史同夜闭环统计排除尾仓及其开仓费，而本用户已确认日末按成本虚拟卖出且两侧各1.70元。本研究坚持后者，记录尾仓原始浮盈亏。没有将外部项目的统计收益当作可迁移收益。

现有64期权、15个已查看交易日共2,914,415帧；947,600帧有买二，942,219帧有卖二。只有32个期权对应的本地同月标的期货有最近5日数据，最多160配对合约日，不能支持原911个期权合约日的完整跨市场估值。QMT最近预检连接不可达。因此本轮为盘口和自身参照的部分迁移，不称为mAu策略完整复制；期权自身历史中价也不是公允价值模型。

## 固定试验合同

新家族`probe_commodity_mau_transfer_20260913_v1`，完整ID为`{family}_{profile}_shared_300000_cost_close`。直接祖先为`probe_commodity_intraday_20260913_v1_edge10_shared_300000_cost_close`。只读历史输入、同一64合约、共享30万元、一合约最多1手、零额外下单延迟、单边1.70元、日末成本虚拟结算和连续现金均不变。

执行前固定七组，未按最终盈亏删掉品种或更换参数：

| profile | 变化 |
| --- | --- |
| control | 旧edge10精确对照 |
| top_exit | 仅取消原五分钟成本卖价保护，按当前卖一改善一tick报价，保持被动 |
| gap | 仅增加买二要求和孤立买一过滤 |
| reference | 仅增加自身价格参照与逆向短时变化过滤 |
| cutoff | 仅在14:55起不再接受新买单 |
| combined | gap＋reference＋cutoff，保留有限成本卖价保护 |
| combined_top | combined再取消成本卖价保护 |

gap在买二不可得时拒绝新开仓；若买一减买二≥max(2tick,当前买卖价差)，拒绝跟随买一。此为无量纲迁移研究阈值，不是用户确认的永久规则；缺买二被拒绝与实际断档被拒绝分别计数。结果必须同时展示剩余合约覆盖，不能把因数据缺失停做某些交易的改善全称为断档过滤效果。

reference采用当前及过去期权中价的150秒/900秒时间EWMA，与当前中价三者取最低。要求至少60秒、3帧预热；该参照减拟买价、再减双边费用后≥max(1tick,双边费用)。若10秒中价下跌≥max(2tick,半个当前价差)，拒绝新买单。每个交易时段重新预热；无效盘口或相邻接收帧超过60秒重置，延续父模型对输入缺口的处理。连续收到相同报价不会因报价不变而被判定为失效。上述参照可能滞后于单边下跌，不假设均值必回归。

旧单必须先按新到达成交证据撮合，然后判断后续报价与过滤，不能事后拒绝旧成交。额外过滤不限制持仓卖出；没有主动止损或亏损只留到日末的规则。期末虚拟成本退出仅执行用户约定的结算。

## 完整结果与补充归因

单边1.70元、0额外延迟、日末按成本虚拟退出，30万元共同钱包。15日全量结果：

| 模型 | 日内研究净收益/元 |
| --- | ---: |
| control | −4,764.50 |
| top_exit | −9,708.20 |
| gap | +925.50 |
| reference | −4,423.10 |
| cutoff | −4,770.50 |
| combined | −4,380.40 |
| combined_top | −7,774.10 |

见到gap转正后，为拆分数据覆盖选择和可见断档机制，另立`probe_commodity_mau_depth_audit_20260913_v1`，ID后缀`_{depth_only|gap_when_observed}_shared_300000_cost_close`，各自仍继承日内edge10。`depth_only`只拒绝缺买二、允许可见孤立买一；`gap_when_observed`只拒绝可见孤立买一、缺买二时继续原模型。两组为结果后归因试验，不能称为预先未见样本外。

- depth_only净−1,012.20元，gap_when_observed净−2,826.80元。
- 保持缺买二处理相同时，断档过滤改善1,937.70元；有买二才交易本身的选择改善3,752.30元，合用为+925.50元。这是完整路径对照，不是将拒绝帧数乘上假想成交利润。缺数据与品种条件相关，不能称为普适流动性优势。
- gap全部正常闭环净+962.90元，11笔日末虚拟闭环双侧费用37.40元，合计+925.50元/0.3085%。尾仓虚拟退出前最后买一累计浮亏−8,987.50元；盘中最大回撤14,171.80元。研究结算把尾仓毛亏损归零，仍不能当作真实市价清仓的完整资金回测。
- gap前10日+1,062.30元、后5日−136.80元；前三大正常盈利合计6,589.80元，删除前三大后的正常闭环−5,626.90元（另有37.40元虚拟闭环费）。盈利依赖少数大单，目前不足以定版。
- 原有成交合约45个，gap只有16个；碳酸锂lc2701-P-158000.GF的120,019帧没有买二，其原−4,317.20元亏损被整体避开，同样也丢掉焦煤等盈利机会。报告保留全部64合约/36品种，缺数据不写成零。
- 自身历史价格参照仅改善341.40元，阻止部分亏损也过滤掉黄金收益，不支持把历史均值直接当作期权公允价。直接跟随卖价使损失额外增加4,943.70元，故mAu的无成本底价出口没有在这一期权样本中泛化；有限被动成本保护仍值得保留研究。

价差大并不代表入场便宜：已验证的部分是孤立买一过滤有增量改善；没有验证的是稳定未来收益，以及黄金跨市场参照能否经期权delta/非线性校正后泛化。下一关键证据为更完整同步期货/期权行情及未查看的新交易日，不能靠同一15日反复筛赢家补足。所有旧黄金+8,347.40元等成果、历史64合约和旧模型保持。

归因实现`src/zhaiquant/commodity_mau_depth_audit.py`、入口`scripts/probe_commodity_mau_depth_audit.py`；全量及日期前缀结果存于`广义套利/reports/commodity_mau_depth_audit_20260913/`。报告生成器`scripts/report_commodity_mau_transfer.py`提供九组收益曲线、全部组合/合约/品种日度、尾仓浮盈亏、覆盖率、拒绝原因帧数和逐合约增减收益。


## 最终验收

98项商品研究测试通过（11项本轮新增）；初轮7组与补充2组每组2,914,415帧、64合约、911观测合约日。旧control逐笔经济字段/闭环/日度/盘中曲线精确一致。全部九组从初始状态重跑至9月4日（各1,761,836帧），保留日末虚拟结算及所有委托、成交信号字段后，前缀一致。初轮冻结执行器的`--prefix`曾因内存嵌套tuple与JSON list直接比较失败；新增`scripts/verify_commodity_mau_transfer.py`统一JSON表示后重跑通过，旧策略引擎、全量结果及合同源码未改动。续验请使用该独立校验入口，勿把序列化类型差异误判为经济路径差异。
