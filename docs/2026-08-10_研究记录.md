# 2026-08-10 G三峡EB2研究记录

## 1. 研究对象

- 可交换债：`132026.SH`，G三峡EB2
- 标的股票：`600900.SH`，长江电力
- 关系：债券持有人可按条款将G三峡EB2交换为发行人持有的长江电力股票。
- 研究目标：寻找日内短暂错价、盘口恢复和被动挂单获取价差的机会。

本次研究重点不是长期持有价值，而是近期价格和订单簿状态下的短周期交易。

## 4. 历史换股溢价观察

集思录长期走势图显示，G三峡EB2的换股溢价率曾在接近0%至35%以上之间变化，存在明显的长期状态切换。因此：

- 长期固定溢价率不能作为稳定合理价值。
- 当前2%或3%的溢价不代表未来仍应维持该水平。
- 强赎、正股位置、波动率、信用、剩余期限和流动性都可能改变溢价中枢。

但是本项目最终决定不以长期溢价估值作为主交易依据。策略目标是近期盘口均值回归，而不是长期基本面定价。

## 5. M0旧模型的一个月回测

回测区间：2026-07-10至2026-08-10，共22个交易日。

基本规则：

- 最近约60分钟的换股溢价率中位数作为局部状态。
- 当前卖一价格相对该状态低估0.8%以上时买入。
- 偏离收敛至0.1%以内，或最长持有时间到达时退出。
- 卖一买入、买一卖出。
- 一次只持有一笔，退出后冷却10分钟。
- 不设置普通紧止损。

回测结果：

| 指标 | 结果 |
|---|---:|
| 交易数 | 11笔 |
| 涉及交易日 | 9日 |
| 胜率 | 100% |
| 单笔平均毛收益 | 约0.49% |
| 单笔中位数 | 约0.40% |
| 满仓逐笔复投样本收益 | 5.54% |

以上结果已使用卖一买入、买一卖出，因此包含买卖价差，但不包含券商佣金。它是假设每笔都使用全部资金的策略收益，不是建议仓位。

### 5.1 收益来源拆解

| 类型 | 交易数 | 未对冲简单收益贡献 | 分析性对冲后贡献 |
|---|---:|---:|---:|
| 盘口偏离实际收敛 | 7笔 | +4.35% | +4.77% |
| 到时仍未收敛 | 4笔 | +1.06% | -1.62% |
| 合计 | 11笔 | +5.41% | +3.15% |

分析性对冲是为了识别利润来源，不代表用户账户一定能够或应该卖空长江电力。

结论：

- 约80%的未对冲简单收益来自7次真正的局部偏离收敛。
- 4次超时交易的相对价值合计为负，但正股方向帮助未对冲债券最终盈利。
- 全部11笔未对冲复合收益为5.54%；剔除正股方向影响后的分析性复合收益约3.17%。

### 5.2 7月28日极端路径

第一笔7月28日交易约在135.49元买入，随后盘口买一最低一度到126.90元，按买一标记的最大盘中回撤约为-6.34%。模型没有止损，60分钟后在135.97元附近退出，最终小幅盈利。

这笔交易说明：

- 旧模型能取得11笔全胜，部分依赖不在宽价差和极端波动中止损。
- 最终盈利不代表持有路径安全。
- 满仓使用该模型会承受无法接受的单笔波动。
- 真实模拟盘必须记录最大不利波动，而不能只看最终收益。

## 6. 盘口和被动挂单研究

过去22个交易日的有效一级盘口中：

- G三峡EB2买一卖一价差中位数约0.18元。
- 约相当于价格的0.13%。
- 在11次原始0.8%信号附近，价差中位数约0.16元。

相对“卖一买、买一卖”，如果买入和卖出两端都能以被动挂单成交，理论上每笔最多可改善约0.25个百分点。将该改善机械加入原样本，满仓月收益的理想上限约为8.47%。

这个上限不能作为预期收益，原因包括：

- 挂在买一或卖一不等于排在队首。
- 追随最优报价撤单重挂会失去时间优先级。
- 被砸成交通常伴随价格继续向不利方向移动。
- 一级行情不能可靠还原排队和部分成交。
- 两端同时被动成交的联合概率明显低于单边成交概率。

## 7. 复杂条件估值模型的研究结果

研究中曾构建条件溢价模型、动态Delta模型、残差波动门槛和强赎过滤。该模型每天仅使用此前数据训练，没有使用测试日收盘信息。

一个月对照结果：

| 模型 | 交易数 | 样本收益 |
|---|---:|---:|
| 双模型共识、固定0.8% | 2笔 | -0.86% |
| 双模型共识、2.5倍动态噪声 | 1笔 | +2.59% |

动态门槛在约1.93%至3.60%之间，导致交易极少。唯一正收益交易只比门槛多约0.008个百分点，且结果对十几秒的入场时间非常敏感，无法据此证明该复杂模型有效。

最终决定：

- 复杂估值不作为主交易模型。
- 保留其代码和输出，作为研究对照和风险标签。
- 不允许它拦截M0局部盘口信号。

## 8. 最终研究结论

1. G三峡EB2与长江电力之间存在可观测的短期盘口错位。
2. M0一个月5.54%的样本收益有实际的局部均值回归来源，但样本非常短。
3. 未对冲收益中混有正股方向收益，不能全部归因于盘口能力。
4. 不止损让模型避免在极端宽价差中卖出，但也带来较大尾部风险。
5. 被动挂单可能增加单笔利润，但成交率、排队和逆向选择是核心问题。
6. 主策略应保持简单：近期价格锚、局部偏离、被动流动性和严格仓位控制。
7. 下一步只做实时模拟，不发送真实委托。
