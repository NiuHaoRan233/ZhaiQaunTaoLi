# 商品期权日内成本虚拟结算研究

## 用户明确规则（2026-09-13）

用户纠正商品期权策略核心为日内，不接受以跨日持仓盈利作为目标结果；收盘未平仓按“该笔买入开仓价”虚拟平掉，毛盈亏归零、仍扣买卖双侧各1.70元。次日空仓；现金保留累计结算后的损益，不每天重置本金。

这是用户指定的研究结算规则，不是声称能在市场收盘时以成本成交。正常日内被盘口成交证据撮合的闭环，与日末成本虚拟结算分别列示。收盘前的最后有效买一浮盈亏、报价时间、陈旧程度和成本结算估值调整保留，以便继续研究尾仓问题。虚拟平仓时没有使用后日价格或后日成交来改写当日。

## 新模型及完整流程

家族`probe_commodity_intraday_20260913_v1`，独立ID为`{family}_{profile}_independent_cost_close`，共享ID为`{family}_{profile}_shared_{人民币元}_cost_close`。继承上一轮六种入场profile：base、edge_fee、edge10、flow2、fresh60、edge_flow2；全部延续原日内撮合和有限退出保护，唯一共同的新日末结算规则如上。原始64合约全部保留，单合约最多1手，额外下单延迟0毫秒。

每个交易日期正常处理所有可用日盘行情。旧有效委托先撮合，再按该帧新信息判断后续委托。北京时间15:00取消未成交委托；若有1手库存，以它的实际入场成本生成`virtual_cost_close`记录，毛盈亏0，新增卖出手续费1.70元，加上开仓时已扣1.70元，该虚拟闭环净−3.40元。入场成本虚拟卖出不要求末笔成交证据，也不伪装成有证据的盘口成交。

该日若没有持仓，不产生虚拟成交或额外费用。虚拟结算后库存和全部待成交委托为零，清空短窗证据；正常日内已经平仓的利润保留。下一观测日重新预热、从空仓开始，但使用前日剩余现金；每个日度净收益是该日终值相对前日结算值的变化，不是将旧跨日交易简单删除。

独立账户保持原每合约预算，总和169.8万元。共享模式使用一个共同钱包，接受买单时冻结买入价和单边手续费、撤单释放、成交扣款、卖出回款；日末成本结算相应更新钱包。保留旧子账本预算仅作单合约上限，不另行注资。按市场时间、同刻合约代码升序处理，相同时刻全部更新完成后计算组合回撤。

完整试验：六种profile各300,000元共享本金；另有base的1,698,000元共享核验组，以及edge10的200,000/500,000元资金对照，共9组共享和384独立账户。先执行全部固定试验，再报告结果，不按最终盈亏删去品种。

## 数据与收益口径

- 输入仍为2026-08-24—09-11的已查看日盘L1历史，不包含夜盘；15个交易日、911有效合约日、每模型49个缺失日格。无数据的合约日保持缺失，不捏造新观察。因前一天已经结算，不允许用缺失日隐藏跨日库存。
- 主展示“成本虚拟结算研究收益”：正常日内闭环净收益＋日末虚拟闭环净收益。没有跨日闭环或期末库存。
- 另外列“虚拟平仓前最后买一浮盈亏”。正数表示尾仓按最后报价浮盈，负数表示浮亏；按成本虚拟结算会将其归零，估值调整为该浮盈亏的相反数。这个调整不是市场成交收益。
- 累计研究收益减去累计成本估值调整，仅是同一路径下的估值敏感性核对，不能宣称为按买一真实强平后的完整回测：那样会改变现金和后续成交。
- 正常成交仅使用既有L1末价最多1手推断证据，仍未校准真实排队与冲击。盘口陈旧的虚拟平仓单独计数。新日内研究没有接入券商交易或替换旧纸面账户。
