## 执行修复范围

1. 已获唯一资金槽、在当前帧前留存的被动单先结算；只检查订单身份、现金、数量、库存和锁债约束，不重新打“是否值得买”的分。方向校正后的被动买入也走此路径，不再因原因字符串被误当主动新意图。
2. 被动买卖单都必须满足`created_ms < tick.market_ts_ms`。同毫秒另一回调不证明挂单已先到交易所；不消费本帧成交，也不挤占其他早已存在卖单的成交量。
3. 本帧分析和原生决策在旧单结算后执行一次；新信息可以撤余单、修改卖单或决定后续新单，不能反写已经结算的仓位。部分库存仍锁债，全部卖清才重新分配。
4. 主动新意图继续接受父版事前风险/两债评分。增加五档对手盘容量预算，同时间戳同价已模拟消耗量不重复供给；不足量仅部分IOC成交、余量取消，不虚构五档以外深度。历史24日155次主动尝试没有触发裁量，因此不把本项防护冒充历史新增收益。
5. 本债到新快照后旧影子失效，须由当时原生合法候选重新生成。不能仅因旧分数还没超过9秒就忽视当前原生无意图；另债仍保留最近已知候选和TTL。该修正会改变驻留起点，正反代价均保留，不擅自修改60秒/50评分元/30%门槛。

实现隔离在`shared_thousand_maker_v016_research.py`。普通引擎拒绝套用0.16身份；因果引擎也要求专用分配器配套。共享回放只增加默认仍为旧引擎的可选构造入口。订单和日账户仍记录准确模型与父ID。
