# 黄金期权双方向与期货定价研究

## 目标与执行前设计（2026-09-13）

固定au2610C960.SF、au2610C952.SF及2026-09-11日盘，首30分钟只作定价/信号预热与此前选约，不按新利润换代码。研究纯买后卖、纯卖后买、期货趋势过滤、期货驱动相对合理价选方向，以及期货先动时提前撤单。目标是解释亏损并找可行模式，不以成本归零、事后择时或筛掉亏损合约制造盈利。

用户此次明确主研究口径：10:15、11:30、15:00余仓按入场成本虚拟退出，正常已完成的亏损保留，买卖两侧各扣1.70元。此轮取消上一版提前5分钟的统一停开限制，允许到休市前交易，边界虚拟退出明确标记；另跑提前5秒停新开、按有效对手价退出的实际计损对照（已有末帧通常离边界1.5—2秒，1秒窗口不足）。虚拟归零前浮盈亏、陈旧价、正常闭环和两种结果分列。

两种方向每次只持有一手，独立资金统一使用25万元：此前15万元少于当前目录期货16%风险比例下约15万元另加期权回购资金的裸卖期权压力占资，不能把卖方权利金收入当作免费资本。卖方以期货名义金额的20%另加期权回购金额作保守研究准备金，25万元给这一约20万元占用留余量；20%并非交易所或账户已核实保证金。保留占用峰值与资金不足拒绝，旧15万元账户不改。做空仅离线纸面研究，无券商交易。

定价先用Black-76零利率欧式近似，波动率从严格历史的当前合约盘口反推并平滑，用同月期货最新可用价格重估；黄金期权美式条款与波动率曲面尚未完整建模，所以这是相对估值信号而非无误差理论公允价。不得先用当前期权价格校准波动率再声称识别当前偏离。同时间戳期权先处理，期货后处理，防止假定未知到达先后。历史L1快照没有真实接收时刻，期货延迟与保守撤单需敏感性核查。

撮合仍只使用之前已生效订单、后到达快照的严格相反侧末价、最多一手，零额外下单延迟；期货在期权聚合成交区间内触发撤单时，保守先允许该区间旧单成交，不把聚合成交错当撤单之后的成交。先做基础买/卖对照和定价/趋势消融，不宣称一个开发日能够证明长期稳定。

## 亏损原因与改善机制

用实际成交帧的中价精确分解：净收益=入场相对中价优势＋持仓中价变化＋退出相对中价优势−费用，方向为多+1/空−1；所有正常闭环逐笔核对。C952纯做空两端优势290+500=790元，被持仓中价变化−2,190元和380.80元费用覆盖，净−1,780.80元。这是逆向成交/持仓风险，不能只责怪手续费。

C960纯多入场优势40元，定价过滤后700元，交易142→55；定价组持仓中价+90、退出优势+50、费用187，净653。C952定价组入场优势860、中价漂移−340、退出优势−280、费用166.60，净73.40；与C960相比仍损失较多持仓和退出优势。固定入场IV下的期货变动进一步解释一部分漂移，剩余项包含IV、报价与模型误差，不等于纯波动率收益。

期货信号额外延迟0/500/1000ms时，做多定价实际合计726.40/1,802.20/671.20元，C960653/939/79、C95273.40/863.20/592.20。虽然这三档均正，逐合约盈亏幅度差异较大，信号对齐改变IV估计与入场，不按500ms最高值寻优。双边择向在部分延迟档转正，也不能借此忽略0/1000ms亏损。

一秒中价变动的描述性相关：C960同刻0.3900、期权滞后1秒0.2248、2秒0.0230；C952为0.3654/0.2486/0.0443。存在短暂滞后线索，但采样、重叠窗口和未知真实到达时刻使其不能证明固定可交易的一秒优势。分析脚本`audit_gold_direction.py`，本地`gold_direction_attribution_20260913`。
