## 实时输入与恢复

复用0.16 r2已验证的接收日志处理机制，日志由模型ID隔离：

- 决策时间取接收时间、已见源时间与上次决策时间的最大值，源时间单独保留。
- 已挂旧单先结算，再更新盘口和评分；新坏评分不能取消已经触发的旧成交。
- 只有源成交时间严格晚于订单创建决策时间、新增成交量、相容推断方向和到价证据
  同时成立才撮合。同毫秒和晚于成交才创建的订单不能成交。
- 同证券时间或累计成交字段回退的输入保留日志但不回滚状态；跨证券异步旧报价
  仍按实际接收顺序处理。恢复只用本模型的`maker_shared_arrival_events`，日合同存于
  `maker_shared_arrival_days`；未处理过的raw、启用前行情和补录数据不倒插前向账户。
- 接收日志先于账户变更写入。处理失败后停止经济推进，重启核对冻结合同并确定性恢复。
