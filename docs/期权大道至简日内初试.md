# 期权大道至简日内初试

2026-09-09，用户要求先用债券日内模型，尤其大道至简，对已观察期权粗试。结果不支持直接把宽价差视为稳定可获利润：三只成交较连续的沪市500ETF在原L1口径均毛亏；原口径正收益合约也对费用、延迟和成交筛选敏感。

## 身份和迁移范围

独立离线家族`probe_option_dadao_20260909_v1`。借鉴归档`probe_top_compare_20260908_v1_fixed_132026`和`fixed_132024`的固定单标循环，不声称复跑整个实时r2或双债v013择标。普通2.x使用债券专属承托、金额、合理区及正股输入，本次未机械移植。现有九模型矩阵、账户、代码路径和配置均不变。

模式ID：`{family}_{mode}_q{capacity}_f{fee_cents}`。mode为`improve_l1`、`improve_single`、`improve_single_d500`、`improve_single_d1000`、`queue_single_d500`；容量1或5张，分别10000或50000元独立初始现金；单边每张费用0/200/300/500分。每个模式/费率/容量/证券/日期为独立账户。只模拟2026-09-09九只归档期权，每模型的不同证券不共享资本。

## 执行合同

- 空仓挂买一、首次部分买成即转卖实际持仓、卖清再买、亏损照卖。改善模式价差大于一跳才向内改善一跳，否则停在买一或卖一。禁止负库存或补资，现金足够支付权利金及费用才可买整数张。
- 九只元数据均核实单位10000份、最小报价0.0001元/份，即每张每跳1元。引擎价格和现金均为整数分/合约张，不能套债券1手10张或原1000张容量。
- 交易窗口09:30—11:30、13:00—14:57，午休撤委托、保留现金库存，未用集合竞价或未来行情。快照按市场时间稳定排序、同时间取最后；这不是接收时序重放。
- 旧单先结算，再更新报价。原L1用末价对前买卖一或末价变化推断方向，并把相邻累计量增归至末价，是理想快照归属；single仅认新增一笔、金额与价量匹配误差≤0.02元、前帧不早于2秒且有效、末价到或穿前买卖价。方向仍是推断，single不是收益下界。
- 500/1000ms档在请求到期后的首个快照生效，区间旧单先结算后应用撤换；每次有一个待生效请求，不让每帧请求挤掉它。到达后限价若跨价，按当前对手方一档可见数量成交，记录`arrival_cross`；未触发跨价才被动等待。当前区间成交不能灌给刚生效新单。延迟档因此可能包含主动成交，不是纯被动做市，且未按真实接收数据校准。
- 排队档沿原买卖一，生效时该价显示量为前队，只从相容真实成交扣前队，不凭盘口减量推定撤单让位。改价重排，跨价末价也先扣前队；无L2真实队列/隐藏单信息，不构成真实成交证明或严格上下界。
- 费用逐笔扣现金。主报毛值和假设单边3元，另列单边2/5元。实际券商费率尚未提供，假设不登记为项目标准。无ETF对冲、隐含波动率过滤或实测交易接口频率约束。
- 日末只按最后有效买一估值，不宣称已经卖清；另按可见五档测算假想清仓并计剩余卖出费，超深度部分拒绝输出完整清仓估值。完整回合时长按墙钟，可能包含午休。没有隔夜收益验证。

## 验证与复现

引擎为`src/zhaiquant/option_top_cycle_research.py`，入口`scripts/probe_option_top_cycle.py`，测试`tests/test_option_top_cycle_research.py`。26项专用及原极简测试通过。9个原L1/1张/零费账户，将每张合约映射1000个合成债券及对应价位后，和未修改的归档固定单标实现逐笔时间/数量/价格/毛值完全一致。不能将此核验扩成真实成交证明。
