# 文档索引

最后更新：2026-08-21

本目录保存项目的长期策略记忆、可执行规格、模型注册表、日常运行手册和历史研究记录。聊天记录不是跨会话真源；每次策略讨论都应把确认后的原则和冲突写回对应文档。

## 策略核心：每次讨论前完整阅读

1. [主观做市策略手册](主观做市策略手册.md)：用户推理、案例、纠正、冲突和统一决策原则的长期真源。
2. [做市策略V0.1](做市策略V0.1.md)：当前形式化、可实现的规则、成交口径、账户边界与已知限制。
3. [做市模型版本记录](做市模型版本记录.md)：不可变模型注册表、父子关系、生产/实时比较指派、回放证据和晋级条件。

三份文档分工不同：手册回答“为什么这样判断”，规格回答“程序现在应怎样判断”，版本记录回答“哪个模型实现了哪些变化”。历史模型不得在原 ID 上静默改写。

- [Windows换机迁移教程](Windows换机迁移教程.md)：新电脑部署、配置和 SQLite 一致性迁移。

- 根目录 [AGENTS.md](../AGENTS.md)：Agent 的持久化策略工作流、安全边界、数量单位和刷新窗口。

## 逐笔证据与机会审计

- [2026-08-15逐笔机会审计](2026-08-15_逐笔机会审计.md)：通达信逐笔成交/委托提取、机会底表、库存路径和模型对照方法。
