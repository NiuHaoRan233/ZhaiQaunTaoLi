# 文档索引

最后更新：2026-09-02

本目录保存项目的长期策略记忆、可执行规格、模型注册表、日常运行手册和历史研究记录。聊天记录不是跨会话真源；每次策略讨论都应把确认后的原则和冲突写回对应文档。

## 策略核心：会话快速启动

1. [做市策略会话启动摘要](策略会话启动摘要.md)：新会话先校验并完整读取的短摘要；它只负责快速恢复当前状态和路由原文，不是第四份策略真源。
2. [主观做市策略手册](主观做市策略手册.md)：用户推理、案例、纠正、冲突和统一决策原则的长期真源。
3. [做市策略V0.1](做市策略V0.1.md)：当前形式化、可实现的规则、成交口径、账户边界与已知限制。
4. [做市模型版本记录](做市模型版本记录.md)：不可变模型注册表、父子关系、生产/实时比较指派、回放证据和晋级条件。

新会话由仓库 skill `.agents/skills/maker-strategy-session/`校验摘要来源指纹。指纹一致时按案例搜索并阅读相关原文，不再把三份长文全部通读作为固定启动动作；摘要过期、原文冲突或全面审计时再按工作规范升级读取。三份真源分工不变：手册回答“为什么这样判断”，规格回答“程序现在应怎样判断”，版本记录回答“哪个模型实现了哪些变化”。历史模型不得在原 ID 上静默改写。
