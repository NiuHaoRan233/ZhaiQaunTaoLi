# 黄金期权之间的联动预警研究

用户提出将其他期权的变化作为慢反应目标的风险/预测信号。本轮在2026-09-07至09-11、1%门槛的已冻结每日新目标上，测试估值耐心、靠山快撤两种策略，独立先多/先空、完整日盘/仅下午、普通/严格成交，共640账户。没有测试其他七策略、1.5%/2%或夜盘，也没有替换实时模型。

## 因子与对照

每天09:30之前从同标的、同到期、同认购/认沽合约选择三个邻居：合格报价行≥90%、中位相对价差≤3%、前缀量增≥20手；合格者八个最近行权价中按量取前三。排除目标和旧C960/C952。23个独立日期/参照合约的全日输入前缀与原冻结前缀核心行情字段完全一致，不按未来收益选参照。

对每张期权，使用不晚于期权源时间且最多陈旧两秒的期货报价，反算Black IV（黄金美式期权的近似）。固定十秒前目标IV。future_only保持该IV不变，以当前期货/剩余期限重新计算目标参考价；peer_cancel额外加上各邻居的十秒IV变化，得到三个目标参考价。至少两个有效邻居及参考价中位数都指向目标不利方向超过两跳才限制新增仓/申请撤单；peer_exit再允许持仓按下一有效目标帧的当时对手价退出。原策略中已有期货规则全部保留。缺少两个有效邻居时不新增动作；期货对照限制在同样数据完整的覆盖集合。

公式：邻居j给出的目标预测价 = Black(当前期货，目标行权价，当前剩余期限，目标十秒锚IV + 邻居j当前IV − 邻居j十秒锚IV)。十秒锚为该时点之前最近报价，允许最多两秒陈旧，同连续时段。新鲜度、十秒、三邻居/两票、两跳均为首轮候选参数。不同执行版本没有收益搜索或事后逐日切换。

这既包含期货带动，也包含跨期权相对IV偏离，不能把所有报警称为“别的期权已经先跌”。同帧目标和原期货动作先执行，联动信息随后交付，不能靠同帧信号取消当前帧的旧聚合成交。撤单若落在未知成交区间内，按父版保守保留可能成交；强平先结算旧区间，再以当前盘口成交。目标已补涨/补跌、差距消失时预警解除。信号原始输入截断重算不改变前缀。

## 五日结果

估值先多普通原策略1262.40元，新增期货十秒重估1532.60元，联动1696元：相对原版+433.60，相对期货对照+163.40。严格952.60→1222.80→1506.20；普通回撤3436.90→3173.50→2930.10元。改善集中09-10/11，早三日净收益不变。正常循环64→60，尾仓排除毛浮亏三者均3940元；因此不是通过增加尾仓剔除金额得到提升，但总体仍依赖用户指定剔除口径。

先空原4028→联动3641.60，下降386.40元；严格也下降。靠山快撤联动撤单先多415.40、先空47.80，与原版相同；已有严格入场/快撤条件下未见额外收益。期货十秒对照靠山先空反而174.60元，不应把期货改善冒算成期权联动收益。

联动主动退出估值先多219元、先空2150.60元；靠山先多355.40、先空−12.20，均比原策略差。退出还会改变尾仓排除额度，不能只看尾亏减少便认定风险收益改善。

仅下午：估值先多607.80→联动778元，先空1853.80→1717.20；靠山309.40/365.20不变。候选适用范围与方向不同，暂不将联动作为统一强平条件，不晋级。

## 区间预警核对

只审计原订单创建至成交前的正常闭环，不包括开仓前已经存在的信号，不把旧亏损加总当作实际增益。必须不晚于成交帧的前一快照，才称明确位于成交区间之前。估值先多联动提前标记4笔亏损和2笔盈利，相对期货独有2笔亏损和1笔盈利；先空1笔亏损、7笔盈利，相对期货独有两笔盈利。误撤机会随方向变化，不能看到相关性就强平。
