# 商品期权共享资金与第二轮优化

## 授权与研究合同（2026-09-13）

用户认为旧主策略15日收益率1.2862%偏低，明确要求“想办法提高点”。本轮同时检验资本利用和入场质量，保持单边每手1.70元、额外延迟0、64合约全名单、单合约最多1手；不通过加杠杆、把旧利润除以占用峰值或事后挑赢家宣称收益改善。旧商品研究、金银铜/铂盈利路径及既有纸面模型全部保留；新研究没有实时指派。

新家族`probe_commodity_capital_20260913_v1`继承不可变`commodity_flow_20260913_v0_1_r2`主策略撮合及退出，独立账户ID为`{family}_{profile}_independent`，共享账户为`{family}_{profile}_shared_{初始人民币元}`。执行前冻结6种profile：

| profile | 新增入场条件 |
| --- | --- |
| base | 原主策略，作为精确等价对照 |
| edge_fee | 拟买卖空间扣双边手续费后，至少再剩3.40元 |
| edge10 | 上述净空间至少10元 |
| flow2 | 近300秒有效主动买/卖末价证据各至少2次 |
| fresh60 | 有效主动买/卖证据各至少1次，但窗口缩为60秒 |
| edge_flow2 | edge_fee与flow2同时满足 |

所有变体继续要求旧规则的至少双边费用加一跳空间；不改变持仓退出、不虚构强制盈利平仓。先结算旧有效委托，再用新快照判断后续开仓，不能看到新不利行情就撤销本来已成交的旧单。证据计数不等于交易所逐笔流，也不把整段量增全部当成该价格可成交量。

独立账户全量比较后，从非base中按前10日净收益减去该阶段最大的3笔盈利闭环排序，选一组与base进入共享资金测试。这是预先写入合同的小规模研究选择规则；所有日期此前已经查看，后4日与9月11日只能称时间分段比较，不能称未触碰样本外。

## 共享资金合同

每个共享模型独立拥有10万、20万、30万或50万元初始现金，零库存、跨日不重置。额外169.8万元base对照须逐笔复现64个原主策略账户，证明资金适配本身没有改写原来经济路径。

全市场输入按市场时间递增，相同时间按合约代码升序处理。每次接受买入挂单立即冻结买价及单边手续费；成交实际扣款，撤单解冻，卖出到账。重报高价需要重新检查资金，不能只在最终成交时才检查；其他合约待成交买单也占用可用现金。相同时间的全部净值变化完成后再计算回撤，避免同一时刻的处理顺序制造额外回撤。资金分配顺序仍是假定的确定性顺序，尚非真实接收顺序验证。

保留原每合约预算的虚拟子账本作为单合约预算上限，子账本初始现金不是真正另行注资。唯一真实研究资金为共享钱包：钱包现金加全部买一估值等于初始本金加子账本净收益和；每帧要求现金非负且覆盖全部挂单冻结额。预算上限暂未优化，每合约最多1手，不根据曾经盈利而给某合约更多手数。

全局交易时段切换取消所有模拟委托；缺少新行情的合约在时段内继续占用原挂单冻结额，直到该合约再次更新或全局时段切换，不能假定资金早已释放。缺失日持仓沿用最后买一估值，单合约缺失日表格仍为空。这种L1日盘研究不覆盖夜盘跳空、真实排队、冲击和行权风险；不连接券商交易接口。

## 实现与证据

新实现`src/zhaiquant/commodity_capital_research.py`，执行脚本`scripts/probe_commodity_capital.py`，测试`tests/test_commodity_capital_research.py`。执行前合同、原始输入哈希、独立和共享账本分别保存于本地`广义套利/reports/commodity_capital_20260913/`。本轮结果应同时报告人民币净收益、真正共享本金收益率、盘中最大回撤、全部日度、资金拒绝和原盈利机会的损失，不只报告最优百分比。

## 完成结果及追加研究

六组×64独立账户已完成。base净21,839.70元、edge_fee为21,881.10、edge10为22,460.40、flow2为4,152.90、fresh60为9,574.40、edge_flow2为4,183.50。执行前排序选到flow2，但其后4日−1,611.50元且全期利润明显退化，不能因前段表现好就推广。缩短成交证据时间及重复要求双侧成交并未普遍提高赚钱能力。

edge10总利润较旧主策略增加620.70元，盘中回撤金额由22,181.30降至19,173.60元。看到此结果后，明确追加20万/30万/50万元edge10共享研究，使用未占用的新ID`{family}_edge10_shared_{200000|300000|500000}`；补充合同及结果在`commodity_capital_extension_20260913`，脚本`scripts/probe_commodity_capital_extension.py`，不覆盖首轮固定搜索合同。这是事后追加研究，非未触碰样本外。

30万元edge10作为优先继续观察的离线候选，20万元作更紧资金对照。收益率提升主要来自共享资金，真实交易利润仅小幅提高；主候选日内闭环仍−2,240.50元，跨日闭环26,461.40元，尾仓−1,760.50元，尚不能确认为稳定价差策略。10万元base虽然收益率19.5304%，盘中回撤19.2898%，不能只按最高百分比选资金。
