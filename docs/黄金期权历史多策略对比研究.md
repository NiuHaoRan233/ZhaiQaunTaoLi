## 选约、数据与失败

每天只用09:00—09:30的报价、成交量及持仓量，沿用原状态筛选及排序。四天主次月均为au2610/au2612，最终均选中au2610C960.SF和au2610C952.SF，故固定原双合约与每日重选是同一组，不冒充两份独立验证。38张黄金认购进入每日初筛，选约JSON先于策略回放冻结；完整下载后重算已选合约首30分钟指标一致。

当前定价实现仅支持认购，选约也限定认购。目录来自当前代码清单和稳定合约条款，通过OpenDate/ExpireDate检查历史上市状态，不以当前报价或主力标签代替历史观察。历史退市合约目录并未完整恢复，不声称遍历完整历史黄金期权全集。

QMT只读下载：期权使用批量下载接口，同月期货使用单代码接口补齐；首次保存的部分期权输入仅首30分钟，已识别为不完整证据而保留，正式回放只使用`full_inputs/`与`full_input_manifest.json`。四天期权日盘有效原始行约1.7万—2.1万/合约，同月期货约2.6万/日，未用分钟线替代tick。

C952在09-08、09-09的10:15前最后5秒没有新tick；其余日末数据与小节边界覆盖保留在`full_coverage.json`。若持仓到此窗口而不能按新有效报价退出，原5秒规则失败：停止该账户、保留最后旧盘口盯市和未平仓，既不复市后卖出也不按成本抹亏。总计1184个标准回放中1106个完整、78个清仓失败，普通/严格可因库存路径不同而出现不同失败。尚需研究时钟驱动的撤挂/主动清仓与有效报价期限，或更早清仓窗口；本轮不为了填满结果临时改变规则。

## 模型与代码

新日期适配家族`probe_gold_history_20260913_v1`，不改任何冻结父模块的全局日期或交易决策。实际自然日先经原`load_frame`构造成交证据，再把全部事件时间平移到冻结引擎的09-11坐标。估值剩余期限用真实ExpireDate的15:00同步平移；输出所有`ts`/`*_ts`、曲线和资金需求时间恢复到真实日期。合约条款必须为黄金认购、1000克/手、0.02元/克一跳。

74结构=25条阶梯/删除/价差规则×多空2方向 + 4条联合简化×2方向 + 14个期货组合 + 2个0.2少追价分支。简化模块中重复的6档纯价差只保留一份；期货组合里的base多空保留作祖先对照。所有结构跑普通及严格穿价，固定8跳的组合不扫描历史最优参数；过去不正确的时间语义、成本虚拟平仓、其他延迟寻优不冒充当前可比策略重跑。

ID为`{family}_{YYYYMMDD}_{case_key}_{code}_capital{整数分}_through{0|1}`。case_key规则映射冻结于`replay_plan.json`，每份摘要同时保存父模型ID、真实日期/到期日和失败状态。每个合约/日/结构/资金/成交假设独立账本；固定选择与动态选择相同的组合只计算一次。不同资金路径若恰好当日现金相同且同模型，按同一模型行为重放，资金场景仍单列。

入口：`scripts/capture_gold_history.py`只读采集；`scripts/validate_gold_history.py --baseline`复核旧日；不带参数回放四日全矩阵，已存在账本复用；`scripts/supplement_gold_history.py`做4万元对照；`scripts/report_gold_history.py`生成报告；`scripts/audit_gold_history.py`独立核对并完成报告。运行环境为根目录`.venv/Scripts/python.exe -X utf8`，绝无xttrader/券商委托。

实现为`src/zhaiquant/gold_history_validation.py`；测试`tests/test_gold_history_validation.py`。68项黄金测试通过，新日期/到期日、时间恢复、时间不修改旧模块、同刻期权先处理、输入前缀和日期筛选有代表测试。09-11的8份0.2交易/报价/撤单/信号/资金路径逐字段一致，100份原规则阶梯经济路径一致。1184个历史账户都做14:00截断前缀回放、资金/费用/证据/库存核验；失败账户明确不要求空仓通过。1106个完整账户共3318个边界空仓。

本地交付：`广义套利/reports/gold_history_20260913_v1/黄金期权_前四交易日全部策略对比.html`，含全部74结构的普通/严格每日表、每策略/日/合约明细、失败清单、收益回撤图、32份小资金对照及全部压缩逐笔账本。HTML表值回读与金额对照，PNG目视检查；未做浏览器截图检查。报告与输入全部本地保存，不加入Git。

本轮只完成比较检验，没有据事后赢家调整正式主版或宣称盈利目标达成。新日期、真实队列及前向交易仍需新增证据；本研究历史可能已在更早商品研究中局部出现，不声称全项目完全未见样本外。
