# 策略自我迭代优化

本目录是第一顺位与排队两个纸面做市分支的持续迭代工作区，方便随时查看进展、证据和代码变更。

## 一眼看进度

- 总体状态与当前任务：[`总进度.md`](总进度.md)
- 可执行代码与测试位置：[`代码与版本索引.md`](代码与版本索引.md)
- 每个候选必须通过的标准：[`验收口径.md`](验收口径.md)
- 第一顺位研究记录：[`第一顺位/`](第一顺位/)
- 排队分支研究记录：[`排队/`](排队/)

## 目录与源码的关系

项目只保留一份可执行真源，避免复制代码后产生两个不一致版本：

- 策略实现：`src/zhaiquant/maker_paper.py`
- 自动测试：`tests/test_maker_paper.py`
- 长期策略知识：`docs/主观做市策略手册.md`
- 正式规格：`docs/做市策略V0.1.md`
- 不可变版本登记：`docs/做市模型版本记录.md`

本目录及时保存候选假设、机会证据、回放报告、风险结论、代码位置和变更补丁索引。任何影响订单、成交、库存路径或执行假设的变化都必须使用新的模型 ID；第一顺位规则不得传播到排队分支，反之亦然。

## 硬性边界

- 全部工作仅限纸面策略和只读市场数据。
- 不导入或调用 `xttrader`，不发送任何真实券商订单。
- 实时判断不得使用未来信息；通达信 `B/S` 只用于盘后验证。
- 不以总收益、交易次数或孤立样本为主要优化目标。
- 数量单位默认是张：1手=10张，1,000张=100手。
- 当前普通账户默认库存范围为0—2,000张，初始底仓1,000张，并有额外买入1,000张的纸面现金能力。
