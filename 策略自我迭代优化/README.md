## 硬性边界

- 全部工作仅限纸面策略和只读市场数据。
- 不导入或调用 `xttrader`，不发送任何真实券商订单。
- 实时判断不得使用未来信息；通达信 `B/S` 只用于盘后验证。
- 不以总收益、交易次数或孤立样本为主要优化目标。
- 数量单位默认是张：1手=10张，1,000张=100手。
- 普通第一顺位1.x/2.x默认按每只债独立账户运行：库存范围0—2,000张，初始客户底仓1,000张，并有额外买入1,000张的纸面现金能力。
- 千张第一顺位0.1/0.11/0.2/0.3/0.31/0.12/0.13是单独0.x家族合同：0张初始底仓，两债合计仅有1,000张买入能力和一个现金槽；各版本使用登记的不可变父版，不得套用普通第一顺位0—2,000张边界或回写旧版归档。
