# 千张第一顺位0.31候选：0.3合并重做0.11走弱退出

研究日：2026-09-02

## 结论与状态

`maker_shared_1000_v0_31_candidate`是不可变0.3的直接子版。它完整保留0.3的
日内韧性候选和风险调整资金选择，只加入当前有效0.11 r2的普通持仓退出空档兜底。
已撤回0.11首版的全批次无条件跟随卖一逻辑没有被移植。

本版已实现并完成09-02完整目标日及08-04至09-01同一21日开发回放。它缩短了
共享资金持仓时间和减少一个终仓日，但总毛值、亏损闭合数和终仓未实现相对0.3
退化。因此0.31是“准确完成用户指定逻辑合并”的独立候选，不是回测全面升级；
未冻结、未加入实时矩阵、未生产部署。

## 精确合并边界

1. 0.3先完整生成、保留、改价或撤销原生卖单。
2. 只有普通`low_bid_reversion`实际批次在父版处理后仍完全没有卖单时补兜底。
3. 兜底必须等待严格晚于买入成交的下一帧，不能复用成交帧旧盘口。
4. 正常挂可靠卖一前一厘；一厘盘口停在卖一，始终保持被动。
5. 父版已有合法卖单时不改价格、不改订单身份。
6. 0.3专属`session_resilient_value_entry`以及深折价、扫尾、联合走廊、邻近
   承托等特殊批次保留原生退出。
7. 重做0.11的孤立低卖、短窗整体重定价、极快离谱跳跌及600秒低约0.30元普通
   再入纪律完整保留。

最重要的边界是第6项。`session_resilient_value_entry`依靠持续高侧成交等复合证据
取得入场许可，属于0.3专属证据型批次；用户没有授权把它重新分类为普通批次。
未来若要让它接受同一止损，必须另建模型ID并审计其原生退出为何失效。
