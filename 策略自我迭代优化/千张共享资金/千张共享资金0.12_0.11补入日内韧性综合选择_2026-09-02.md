# 千张第一顺位0.12候选：0.11补入日内韧性综合选择

研究日：2026-09-02

## 结论与状态

`maker_shared_1000_v0_12_candidate`是当前有效且已归档0.11 r2的直接子版。
因果核对确认0.11仍会在组合比较前删除江铜10:44的日内韧性机会，因此本版完整
补入0.3候选和0.2/0.3风险调整资金选择，同时原样保留0.11 r2普通退出空档兜底。

0.12已实现并完成09-02完整目标日及08-04至09-01同一21日开发回放。它相对
0.11缩短占资、减少成交与亏损闭合、改善最差闭合和终仓浮亏，但累计毛值降低。
当前决策路径与0.31完全等价；两个版本只因合并顺序不同而有不同父链。0.12未冻结、
未加入实时矩阵、未生产部署，也不替换已归档0.11。

## 为什么确认0.11有问题

09-02 10:44:03江铜盘口的父版普通合理价优势存在，但0.20元外层固定承托不足。
0.11 r2的`enable_session_resilient_ordinary_entry=False`，所以136.502意图没有机会
进入共享资金比较：当时账户零库存、现金138,300元，足够买1,000张；首笔实际成交
直到11:29:15才发生，10:40—10:46没有分配事件或成交，三峡也没有占资或更优合法
意图。这证明缺口发生在候选生成阶段，不是现金不足、已有持仓或组合排名失误。

聚焦回归在完全相同的10:44盘口与截至当时成交证据上确认：有效0.11 r2无买单；
0.12形成`session_resilient_value_entry`，价格136.502、数量1,000张。只有一笔高价、
短时集中爆量、当前零承托、低侧不可达或现金/三峡更优时仍不会因此放行。

## 精确版本边界

1. 直接父ID为`maker_shared_1000_v0_11_candidate_r2`，不是已撤回首版0.11。
2. 保留0.11 r2全部普通`low_bid_reversion`退出空档兜底及保护边界。
3. 开启0.3的`session_resilient_value_entry`，并复用`AllocationParametersV03`和
   `SharedThousandV03Allocator`；只开profile而继续用0.1分配器不是本版。
4. 日内高侧韧性、低侧卖出可达性、连续承托、0.2尾部风险、预计锁资时间和现金
   第三候选一起决定是否挂单，韧性不削减下行风险。
5. guarded退出白名单仍只有`low_bid_reversion`。`session_resilient_value_entry`和
   深折价、扫尾、联合走廊、邻近承托等特殊批次保留原生退出。
6. 账户仍为日初零库存、两债共享1,000张、亏损后不补资、最多一个有效买单。

0.12和0.31是同一两项变化按不同父链顺序合并：0.12为“0.11补入0.3”，0.31为
“0.3补入0.11”。当前参数相同时二者行为相同；登记身份、直接父ID和未来演化仍须
严格分开。
