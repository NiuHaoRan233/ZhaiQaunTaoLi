# 行情屏幕高速读取

这是一个独立、只读的屏幕行情采集原型。它不使用 `computer-use`，不操作鼠标键盘，
不进入交易界面，也不调用 `xttrader`。目标是把当前肉眼可见的行情区域，以尽可能低的
延迟转换为带时间戳的结构化 OCR 事件。

## 为什么这样做

数据链路只有四步：

1. `mss` 直接抓取目标窗口的客户区，默认目标为 30 FPS。
2. 只检查人工框选的行情区域，不识别整张屏幕。
3. 用 OpenCV 图像差分判断区域是否真的变化；未变化就完全跳过 OCR。
4. 把滚动表格切成固定行，用 RapidOCR 的“仅文字识别”模型直接批量读新增行，绕过最慢的
   通用文字检测模型。
5. 新增行进入先进先出的内存队列；抓屏不等待 OCR，识别稍慢时显示积压量，但不静默丢弃。

这种方式比通用界面自动化轻得多。抓帧和变化检测通常是毫秒级，行级识别也比整块 OCR
快得多。第一版先保留行级 OCR 结果；盘口布局稳定后，可以把数字、`B/S/BC/SC`
换成固定字形模板识别，进一步降低延迟。

## 当前边界

- 行情软件必须处于已登录、未最小化、没有被别的窗口遮挡的状态。
- 本工具只读取屏幕上已经显示的像素，不负责搜索证券、切换页面或翻页。
- 不保存密码、账户信息或交易界面截图。
- 原始变化截图默认不保存；需要审计时可在配置中开启。
- OCR 结果带置信度，不确定内容不会被悄悄修正成一个看似确定的数字。

## 安装

在项目根目录执行：

```powershell
.\.venv\Scripts\python.exe -m pip install -r .\行情屏幕高速读取\requirements.txt
Copy-Item .\行情屏幕高速读取\settings.example.json .\行情屏幕高速读取\settings.json
```

`settings.json` 是本机布局，已被本目录的 `.gitignore` 忽略。

## 使用

先列出可见窗口，确认标题：

```powershell
.\.venv\Scripts\python.exe .\行情屏幕高速读取\reader.py windows
```

保存一张完整窗口快照，用来确认抓取正常：

```powershell
.\.venv\Scripts\python.exe .\行情屏幕高速读取\reader.py snapshot
```

逐个框选需要读取的区域。建议分别框选“成交明细”“逐笔委托”“五档盘口”，不要把分时图
一起框进去：

```powershell
.\.venv\Scripts\python.exe .\行情屏幕高速读取\reader.py calibrate --name 成交明细 --row-height 18 --newest-at bottom
.\.venv\Scripts\python.exe .\行情屏幕高速读取\reader.py calibrate --name 逐笔委托 --row-height 18 --newest-at bottom
```

框选期货逐笔成交时让上边缘包含一行表头，下边缘落在最后一条完整数据行的下边缘。
按回车或空格确认，按 Esc 取消。`row-height` 是一行的像素高度，`newest-at` 表示最新记录
出现在顶部还是底部。区域按窗口宽高归一化保存；布局发生明显变化时应重新校准。

开始持续读取：

```powershell
.\.venv\Scripts\python.exe .\行情屏幕高速读取\reader.py run
```

## 收盘后怎么测试

收盘后画面不再变化，但仍能验证程序看到了哪里、静态 OCR 能读出什么：

1. 恢复通达信窗口，放到明天准备长期保持的位置，打开需要读取的行情页面。
2. 双击 `1_框选成交明细.cmd`，从表头开始框到最后一条完整数据行。
3. 如需逐笔委托，再双击 `2_框选逐笔委托.cmd` 进行框选。
4. 双击 `3_收盘后测试读取.cmd`。

期货逐笔成交使用`时间｜价格｜现量｜仓差｜开平`五列表格输出；同一界面下切换品种不必
重新配置。测试会逐行打印文字和置信度，并打开一张带绿色区域框、行分隔线的截图。输出保存在
`runtime/inspection/`。绿色框不对或横线没有贴合每一行，就重新框选；文字对但字段粘在
一起属于下一步“按固定列切分”的问题，不是抓屏遗漏。

明天开盘前保持同样窗口位置和页面，双击 `4_开盘实时读取.cmd`。实时终端除了性能统计，
还会立即打印每条新增行的识别文字；原始事件持续写入 JSONL。

终端每两秒显示实际抓帧速度、送入 OCR 的变化帧数、完成数量和待处理积压量。
识别结果追加写入：

```text
行情屏幕高速读取/runtime/events/YYYY-MM-DD.jsonl
```

每行都包含采集时间、窗口标题、区域名、变化比例、OCR 延迟、新增行位置、识别文本和
置信度。

## 配置重点

- `target_fps`：抓帧目标速度。先用 30；CPU 占用过高可降到 15。
- `pixel_delta`：单像素亮度变化阈值，可过滤抗锯齿和轻微闪烁。
- `changed_fraction`：区域内达到多少比例的变化像素才触发 OCR。
- `min_ocr_interval_ms`：同一区域两次送 OCR 的最短间隔；完整采集默认设为0。
- `save_changed_images`：是否保存每次送 OCR 的原始小图，审计时开启。
- `regions`：校准生成的归一化区域、行高、最新行方向和每次最大识别行数，不建议手填。
