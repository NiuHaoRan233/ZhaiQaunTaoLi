# 黄金期权日内估值做市0.1

固定两份期权的完整离线研究策略：au2610C960.SF、au2610C952.SF，仅先买后卖、每份最多一手。用同月期货重新估值，只有保守参考价仍高于买入价足够多才挂买；成交后按有限等待规则挂卖，三个日盘休市边界清零。

## 使用

双击上级目录`复现黄金期权日内策略0.1.cmd`，或在仓库根目录执行：

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts\run_gold_intraday_value.py
```

程序核验本地保存数据/依赖哈希，重跑两合约的成本虚拟结算、实际价格清仓及严格穿价成交对照，共8份账本，并与冻结结果逐字段比对。没有网络或券商连接。本地研究数据需要保留，不能把只有代码、缺数据的目录当作已可复现。

配置为[strategy.json](strategy.json)，绑定2026-09-11单日及固定模型；不是任意日期实时交易入口。修改参数、日期、资金、标的或执行假设需要新模型身份，旧账本不可覆盖。当前程序不声称已经接入前向模拟盘。

## 完整决策

1. 09:00—09:30观察。每个连续小节重置估值与成交方向窗口，至少预热60秒；09:30后才交易。
2. 期权报价先暂存，等同月期货的原行情时间已达到它，再用不晚于期权时间的期货报价反推IV；间隔最多2秒。校准只有在两边信息都已收到后才可用于后续决策，不回填旧订单。
3. 用Black-76零利率欧式近似分别平滑10秒和60秒IV，取二者较低值。用当前已知au2610期货价格、行权价与剩余期限计算参考价。该相对估值近似不消除美式条款、IV曲面和市场报价误差。
4. 每手乘数1000，报价最小跳动0.02元，一跳价值20元。买价=买一＋一跳；要求双侧改善、双费后空间≥一跳，过去300秒有严格推断双向成交，存在有效买二且买一/买二断档小于max(两跳，当前价差)。
5. 参考价−拟买价−双侧费用≥max(一跳，当前价差的四分之一)才允许买。期货源报价年龄不得超过2秒；无有效估值或盘口则撤买单，不删除已发生的旧单成交。
6. 买入后立即挂卖一−一跳；前300秒保留覆盖双费和一跳收益的成本底价。若中价较入场订单参考逆向超过当时价差且持续30秒，或持仓已达300秒，解除底价，继续被动跟档退出。旧卖单先按新帧成交证据处理，再改新价。
7. 主研究在10:15/11:30/15:00把余仓按本笔入场成本虚拟卖出，毛盈亏归零但买卖各收1.70元；正常亏损保留。独立实际计损对照提前5秒停新买、余仓按当时有效买一卖出。无买一导致清仓失败会报错，不造价格。

初始每份25万元，每个策略场景两份共50万元，现金沿日内连续累计，不能将不同情景相加。无卖空、无加仓、无实盘委托。旧纯空、定价择边、趋势及提前撤单研究失败/退化结果全部保留。

## 验证与解释

固定10/60秒主参数、0额外期货信号延迟：成本口径C960+860.20、C952+497.60元；实际计损+840.20/+417.60元，合计+1,257.80元。严格穿价对照实际+867/+381元。相邻fast5/20秒与0/500/1000ms期货信号延迟都单列，不挑最高利润改主参数。

这些是单个开发日的模拟成绩，不是未来利润保证。C952收益仍比C960集中，真实队列/网络到达时序及新日期尚未验证。当前交付解决的是用户限定的最新日双标的研究与可复现模式；进一步使用应先独立前向模拟验证。
