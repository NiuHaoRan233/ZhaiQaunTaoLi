盘口怎么读

红线是买一，绿线是卖一，按每条可见快照画阶梯线；下方同时显示买卖一挂单量和成交量增。零报价或零数量视为缺档，不画成零价。

B ↑：本次末笔成交价 ≥ 此前有效卖一。S ↓：本次末笔成交价 ≤ 此前有效买一。价差内、前盘口超过60秒、同毫秒、缺档或锁盘时标为灰色 ◆。累计量回退视为重置，首条快照不凭空生成成交。

QMT L1 不是交易所逐笔成交源。一条量增事件可能包含多笔甚至双向成交，标记仅反映该事件末笔价格的方向证据。每条量增都保留，放大或翻页可逐条查看，导出含全部原始快照和事件。

日期使用北京时间自然日：同一天日盘和21点后的夜盘可能属于不同交易日，午夜后的凌晨属于下一个自然日。图中不把休市前后或超过60秒的缺口连成持续报价。主力月按最新标的期货持仓量排序，次主力月为第二名；若无期货持仓则明确回退至各月期权持仓合计。排序不是历史时点排名。

目录、最新行情与合约链覆盖QMT可见全部商品期权。服务运行时订阅各市场全推并记录商品期权快照；断开期间不会自动生成历史，需重取历史补齐。历史按合约、自然日下载并缓存；未返回的数据保持为空。能源中心等缺失市场会在顶部提示。
