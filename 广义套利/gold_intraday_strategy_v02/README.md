# 黄金期权大价差做市0.2（离线研究）

主版是“8跳价差＋期货逆向过滤＋少追价”，只先买后卖；另存“估值择向＋期货撤单”的多空增强对照。固定au2610C960.SF/C952.SF、2026-09-11日盘，不能将此单日候选称为新日期或实盘盈利系统。

## 主版规则

1. 09:00—09:30只观察，09:30以后、每个小节数据预热完成后才交易。每份最多一手，不加仓、不摊平；每份2万元已实际回放验证。
2. 买卖一价差至少8跳（0.16元/克，一手160元），才允许挂开仓单。买一、卖一须有有效报价和数量。原价差扣两侧改善40元及双费3.40元，静态空间至少116.60元/手；不是承诺收益。价差变窄即撤开仓意图，平仓不受此门槛阻挡。
3. 用同月au2610期货判断是否逆向：最近10秒或60秒的期货变化乘当前估计delta，若对应期权向下幅度超过max(两跳,当前盘口价差的一半)，不新买。期货上涨只表示不被此条件否决，仍必须满足价差。期货源报价≤2秒，IV校准≤60秒，每小节预热≥60秒且至少3次校准。这里不要求估值高于买价，也没有额外双向成交或第二档条件。
4. 买一加一跳挂买；已有合法买单时，只在追价至少2跳、原订单存在至少1秒两个条件同时成立才向上改价。原单可暂时落后于最新买一；行情转坏撤单、向下退价、平仓都不受这个限制。少换价不代表保证排到第一或成交。
5. 买入后按卖一减一跳被动卖出；价差只有一跳时不跨价。不设成本保护、不设固定持有300秒，不锁定必须盈利；一手卖完才可再买。
6. 10:15/11:30/15:00前5秒停止开仓，余仓按有效买一主动平仓并扣手续费。无有效清仓报价则失败，绝不按成本抹去亏损。不跨休市、不跨日。

单边每手1.70元，额外下单延迟0。普通成交仍要求挂单先于成交区间、推断对侧、可识别单次成交且末价达到限价；另存必须严格穿价才成交的对照。这不是交易所队列撮合。

## 多空增强对照

同样先过8跳门槛。基于同步期货的快10/慢60秒IV参考价，多头用低值、空头用高值；净估值优势至少max(一跳,盘口价差四分之一)。每一侧再通过10/60秒趋势过滤，合格两侧选择扣费估值优势更大的一边，同分选多；有仓先平、不直接反手或加仓。

持仓沿用原有限成本保护：双费＋一跳底价，300秒到期或中价逆向超过入场价差持续30秒解除，继续被动跟档。期货先更新时，若旧开仓单估值优势/趋势/数据新鲜度不再合格，先撤单；快照聚合区间内可能已发生的成交仍保守计入，不回溯抹掉。只在下一个期权报价做新报价，不能以旧盘口伪造提前平仓。此版本不额外用期货逆向强行解除持仓保护，因为该对照未改善。

同样只限制朝成交方向追价，向安全方向退价和退出立即处理。空头资金仍用20%期货名义金额＋权利金的研究准备金，非券商保证金，不能按主版4万元给它算收益率。
